# It Works στο iPhone σου

Αυτός ο οδηγός είναι για Mac. Δεν χρειάζεται να ξέρεις git ούτε να γράφεις κώδικα. Η εφαρμογή στο τηλέφωνο είναι η ίδια ιστοσελίδα, μέσα σε ένα κέλυφος που λέγεται Capacitor. Τα δεδομένα σου μένουν στο τηλέφωνο.

Κάνε τα βήματα με τη σειρά. Μην παραλείψεις το `npm run cap:sync`, αλλιώς το Xcode δεν έχει την τελευταία έκδοση της σελίδας.

## 1. Εγκατάστησε το Xcode

1. Άνοιξε το **App Store** στο Mac.
2. Ψάξε **Xcode**.
3. Πάτα **Λήψη** / **Get**. Είναι μεγάλο. Άφησέ το να τελειώσει.
4. Άνοιξε το Xcode μία φορά. Αν ζητήσει να εγκαταστήσει επιπλέον εξαρτήματα, πάτα **Install** και περίμενε.
5. Κλείσε το Xcode προς το παρόν.

## 2. Εγκατάστησε το Node.js 22

Το χρειάζεσαι μόνο για να αντιγράψεις την ιστοσελίδα μέσα στο Xcode.

1. Άνοιξε [https://nodejs.org](https://nodejs.org).
2. Κατέβασε το πρόγραμμα εγκατάστασης για macOS, έκδοση **22** (όχι παλιότερη).
3. Άνοιξε το αρχείο που κατέβηκε και πάτα συνέχεια μέχρι το τέλος.
4. Αν είχες ήδη ανοιχτό το Terminal, κλείσε το και ξανάνοιξέ το.

## 3. Πάρε τον κώδικα

Διάλεξε έναν από τους δύο τρόπους. Ο πιο απλός είναι το ZIP.

### Α. Λήψη ZIP

1. Άνοιξε τη σελίδα του repository στο GitHub: `https://github.com/statego2/It-Works-Life-Tracker-`
2. Μέχρι αυτό το pull request να μπει στο `main`, άνοιξε το branch του pull request (όχι μόνο το `main`). Μετά το merge, το πράσινο κουμπί στην κύρια σελίδα φτάνει.
3. Πάτα το πράσινο **Code** και μετά **Download ZIP**.
4. Κάνε διπλό κλικ στο ZIP. Θα βγει ένας φάκελος. Θυμήσου πού είναι, για παράδειγμα στα Downloads.

### Β. GitHub Desktop

1. Εγκατάστησε το GitHub Desktop από [https://desktop.github.com](https://desktop.github.com) και συνδέσου στον λογαριασμό σου.
2. **File → Clone repository → URL**.
3. Βάλε `https://github.com/statego2/It-Works-Life-Tracker-` και διάλεξε φάκελο στον δίσκο.
4. Πάνω στο πρόγραμμα, στο **Current branch**, διάλεξε το branch του pull request. Μετά το merge, διάλεξε `main`.

Δεν χρειάζεται να γράψεις εντολές git.

## 4. Αντίγραψε την ιστοσελίδα μέσα στο έργο του iPhone

1. Πάτα **Command + Space**, γράψε `Terminal` και άνοιξέ το.
2. Γράψε `cd ` με ένα κενό στο τέλος. Μην πατήσεις Enter ακόμα.
3. Σύρε τον φάκελο του It Works μέσα στο παράθυρο του Terminal. Θα γραφτεί η διαδρομή μόνη της.
4. Πάτα Enter.
5. Επικόλλησε αυτές τις τρεις γραμμές, μία μία, και περίμενε την καθεμία να τελειώσει:

```bash
npm install
npm run cap:sync
open ios/App/App.xcodeproj
```

Η δεύτερη εντολή αντιγράφει την ιστοσελίδα στο Xcode. Η τρίτη ανοίγει το έργο. Το αρχείο που ανοίγει είναι `ios/App/App.xcodeproj`. Δεν υπάρχει `xcworkspace`.

Αν το Terminal πει `npm: command not found`, γύρνα στο βήμα 2, κλείσε το Terminal και ξανάνοιξέ το.

## 5. Υπόγραψε με το δωρεάν Apple ID

1. Στο αριστερό μέρος του Xcode πάτα το μπλε εικονίδιο **App**.
2. Στη στήλη των targets διάλεξε **App** (όχι το ItWorksWidget ακόμα).
3. Άνοιξε την καρτέλα **Signing & Capabilities**.
4. Αν δεν έχεις λογαριασμό: μενού **Xcode → Settings → Accounts → + → Apple ID**. Βάλε το Apple ID που χρησιμοποιείς στο iPhone. Δεν χρειάζεται να πληρώσεις.
5. Στο **Team** διάλεξε το **Personal Team** (το όνομά σου).
6. Το **Bundle Identifier** είναι `com.statego2.itworks`. Αν το Xcode πει ότι είναι πιασμένο, άλλαξέ το σε κάτι δικό σου, για παράδειγμα `com.τοόνομάσου.itworks`, και στο target **ItWorksWidget** βάλε το ίδιο με κατάληξη `.widget`.
7. Κάνε το ίδιο Team και στο target **ItWorksWidget**.

Τα App Groups είναι ήδη γραμμένα και στα δύο targets, με όνομα `group.com.statego2.itworks`. Χρειάζονται για να βλέπει το widget τους χρυσούς στόχους. Αν το Xcode δείξει κόκκινο σφάλμα για App Groups με δωρεάν λογαριασμό, η εφαρμογή και πάλι τρέχει. Το widget τότε περιμένει. Για να το ξαναπροσπαθήσεις:

1. Target **App** → **Signing & Capabilities** → **+ Capability** → **App Groups**.
2. Τσέκαρε `group.com.statego2.itworks`. Αν δεν υπάρχει, πάτα **+** και γράψε ακριβώς αυτό.
3. Το ίδιο στο target **ItWorksWidget**.

## 6. Τρέξε την εφαρμογή στο iPhone

1. Σύνδεσε το iPhone με καλώδιο. Ξεκλείδωσέ το. Αν ρωτήσει αν εμπιστεύεσαι τον υπολογιστή, πάτα **Εμπιστοσύνη** / **Trust**.
2. Πάνω στο Xcode, δίπλα στο κουμπί εκτέλεσης, διάλεξε το **iPhone σου**. Όχι έναν Simulator.
3. Πάτα το τρίγωνο **Run** (ή Command + R).
4. Την πρώτη φορά το iPhone μπορεί να ζητήσει **Developer Mode**:
   - Ρυθμίσεις → Απόρρητο και ασφάλεια (Privacy & Security) → Λειτουργία για προγραμματιστές (Developer Mode).
   - Άνοιξέ την, το τηλέφωνο θα κάνει επανεκκίνηση, και ξαναπάτα Run στο Xcode.
5. Αν η εφαρμογή δεν ανοίγει και λέει «Untrusted Developer»:
   - Ρυθμίσεις → Γενικά (General) → VPN και διαχείριση συσκευής (VPN & Device Management).
   - Πάτα το Apple ID σου και μετά **Εμπιστοσύνη** / **Trust**.
6. Ξαναπάτα Run. Η εφαρμογή **It Works** πρέπει να ανοίξει στο τηλέφωνο.

Οι υπενθυμίσεις που βάζεις από το μενού ρυθμίσεων (γρανάζι → Υπενθυμίσεις) χτυπάνε μόνο σε αυτή την εγκατάσταση, χωρίς server. Την πρώτη φορά το iPhone ζητά άδεια για ειδοποιήσεις. Πες ναι.

## 7. Επτά μέρες ή 99 δολάρια τον χρόνο

Με **δωρεάν Apple ID** η εγκατάσταση διαρκεί **7 μέρες**. Μετά το τηλέφωνο σταματά να ανοίγει την εφαρμογή. Ξανασύνδεσέ το στο Mac και πάτα πάλι Run. Δεν χάνεις τα δεδομένα που είναι ήδη μέσα στην εφαρμογή, εφόσον δεν τη σβήσεις.

Με το **Apple Developer Program** (99 δολάρια τον χρόνο) η εγκατάσταση κρατάει περίπου έναν χρόνο και μπορείς να χρησιμοποιήσεις TestFlight. Δεν είναι απαραίτητο για να τη δοκιμάσεις μόνος σου.

## 8. Βάλε το widget στην αρχική οθόνη

1. Στην αρχική οθόνη του iPhone, πάτα παρατεταμένα ένα κενό σημείο μέχρι να κουνηθούν τα εικονίδια.
2. Πάτα το **+** πάνω αριστερά.
3. Ψάξε **It Works**.
4. Διάλεξε το μικρό ή το μεσαίο widget και πάτα **Προσθήκη**.

Στο widget οι χρυσοί στόχοι δείχνουν το **ΤΩΡΑ** αριστερά και τον **ΣΤΟΧΟ** δεξιά. Για να μπει ένας στόχος εκεί, άνοιξε την εφαρμογή και πάτα το αστέρι του.

Αν το widget μένει άδειο και στο βήμα 5 το Xcode δεν δέχτηκε τα App Groups, το widget δεν μπορεί να διαβάσει τους στόχους μέχρι να ενεργοποιηθεί η ομάδα `group.com.statego2.itworks`. Η υπόλοιπη εφαρμογή δουλεύει και χωρίς αυτό.

## Τι δεν κάνει αυτός ο οδηγός

Δεν ανεβάζει την εφαρμογή στο App Store. Δεν συνδέει λογαριασμό cloud. Τα δεδομένα του Safari και τα δεδομένα της εγκατεστημένης εφαρμογής είναι ξεχωριστά. Αν είχες ήδη στοιχεία στην ιστοσελίδα, κάνε **Εξαγωγή** από το γρανάζι και **Επαναφορά backup** μέσα από την εφαρμογή στο iPhone.
